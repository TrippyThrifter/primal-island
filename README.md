# Primal Island

Homepage for the Primal Island Isle: Evrima server.

**Live:** https://primal-island.primal-island-hosting.workers.dev/

## Structure
- `index.html` — homepage
- `404.html` — custom not-found page
- `css/styles.css` — all styling
- `js/main.js` — mobile menu
- `assets/favicon.svg` — claw-mark favicon
- `wrangler.jsonc` — Cloudflare Workers assets config

## Recent additions
- Favicon (claw mark in rust/bone palette)
- Open Graph + Twitter card meta tags (better Discord/Twitter link previews)
- Matching 404 page
- Proper Discord link placeholders (replace `YOUR-INVITE`)

## Deploy
Push these files to the GitHub repo. Cloudflare will redeploy automatically.

Replace every `https://discord.gg/YOUR-INVITE` with your real invite once the Discord server exists.
